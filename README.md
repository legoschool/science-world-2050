# 미래과학탐험 · 망가진 2050을 되살려라

6학년 2학기 과학 네 단원을 의뢰 52개로 나눈 탐험 게임의 핵심 코드입니다. 2050년 마을은 모든 일을 인공지능 척척에게 맡겼다가 척척이 고장 나면서 함께 망가졌고, 학생은 마을을 걸어 다니며 척척이 틀리게 알려 준 과학을 실험과 기록으로 바로잡습니다.

게임 주소는 https://science-world-2050.vercel.app 이고, 선생님용 사용설명서는 https://science-world-2050.vercel.app/manual.html 에 있습니다.

## 파일과 하는 일

| 파일 | 하는 일 |
|---|---|
| `server.py` | 접속 코드 확인, 의뢰 서버 채점과 단계별 힌트, 기록 저장, 관리 화면과 배움 관찰실 API |
| `teaching.py` | 과제 원본 보존, 교사 확인, 장소별 학급 활동 |
| `inquiry.py` | 발견 탐구의 예상, 시도, 도움, 성찰, 새 조건 기록 |
| `writeup.py` | 자기 말로 설명하기의 낱말 확인과 관찰 근거 기록 |
| `health_inquiry.py`, `health_partner.py` | 기후와 감염병 공동 탐구, AI 연구 파트너 |
| `api/index.py` | Vercel 서버리스 함수 입구 |
| `public/` | 학생 화면(마을 지도, 의뢰, 실험 장면, 도감)과 선생님 관리 화면 |

## 돌아가는 방식

Vercel이 `public/`의 화면을 그대로 내보내고, `/api/*` 요청은 `api/index.py`를 거쳐 `server.py`의 `Handler`가 처리합니다. 기록은 환경 변수 `DATABASE_URL`이 있으면 Postgres에, 없으면 SQLite에 저장합니다. 학생 접속 코드는 평문으로 저장하지 않고 HMAC으로 계정을 찾은 뒤 scrypt로 확인합니다. 의뢰의 정답 열쇠는 서버에만 두고, 학생 화면에는 열쇠를 뺀 내용만 보냅니다.

## 올리지 않은 것

정답 열쇠가 든 의뢰 자료(`data/`), 그림과 사진(`public/assets`, `public/manual-shots`), 시험 코드, 제작 도구, 설명서 원본은 이 저장소에 없습니다. 그래서 이 저장소만 받아서는 게임이 실행되지 않습니다.
